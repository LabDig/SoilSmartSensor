# SoilSmartSensor

Esse repositório reune a documentação para construção da plataforma multisensor SoilSmartSensor. 

O Soil Smart Sensor é uma plataforma multisensor e portátil em desenvolvimento do Depto de Engenharia Agrícola da Universidade Federal de Viçosa. O Soil Smart Sensor permite medir a condutividade eletríca aparente , o teor de água e a umidade do solo. A operação do multisensor é realizado por aplicativo executado em dispositivo móvel Android.


Projeto Financiado pelo Conselho Nacional de Desenvovlimento Científico e Tecnológico (CNPq). Tìtulo : Desenvolvimento de um sistema inteligente para caracterização da variabilidade espacial do solo em agricultura de precisão . Processo 404374/2021-2
