# SoilSmartSensor

# Estrutura

Esse diretorio contém os arquivos relacionados à estrutura (chassi) do Soil Smart Sensor. 

O aplicativo foi desenvolvido utilizando a plataforma online MIT App Inventor (https://appinventor.mit.edu/)


Detalhamento dos arquivos e diretórios

Estrutura.step --> modelagem 3D da estrutura

ListaMateriaisEstrutura.csv --> Lista de materiais e respectivas quantidades para construção da estrutura

DesenhoTecnico.pdf --> Desenho técnico para construção da estrutura
