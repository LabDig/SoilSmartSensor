# SoilSmartSensor

# App

Esse diretorio contém os arquivos relacionados ao aplicativo Android para operação do Soil Smart Sensor. 

O aplicativo foi desenvolvido utilizando a plataforma online MIT App Inventor (https://appinventor.mit.edu/)


Detalhamento dos arquivos e diretórios

/PrintScreen --> contém capturas de tela do aplicativo

BLE-with-extensios-api.apx --> Extensão para usar os recursos do Bluetooth Low Energy (BLE)

SmartSensor3.aia --> arquivo aia gerado pelo AppInventor. Você pode importar e editar o aplicativo a partir desse arquivo

SmartSensor3.apk --> arquivo APK para instalação do aplicativo em dispositivo Android
