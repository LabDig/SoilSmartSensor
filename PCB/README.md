# SoilSmartSensor

# PCB

Esse repositório reune a documentação para construção da placa de circuito impresso para o Soil Smart Sensor. 


A placa é desenvolvida com base na ESP32 S3


O projeto do circuito foi desenvolvido utilizando o Fritzing (https://fritzing.org/)


Detalhamento dos arquivos e diretórios

PCB.fpz --> arquivo Fritzing

PCB_Esquematico.pdf --> ciruito eletronico da placa do Soil Smart Sensor

PCB_trilhas.pdf --> trilhas da placa do Soil Smart Sensor

ListaMateriais_PCB.csv --> Lista de materiais para fabricação da PCB e Unidade Eletronica de Controle

/Gerber --> diretorio com os arquivos Gerber para confecção da PCB
